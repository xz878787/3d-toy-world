# 3D 小世界编辑器 | 3D World Simulator

🌍 **在线体验**：https://3d-world-simulator.netlify.app/

一个轻量、开箱即用的 3D 网格世界搭建模拟器，纯浏览器运行，支持自由放置方块、本地存档、视角交互，零基础也能快速创造专属 3D 小世界，同时也是前端 3D 可视化入门级标杆项目。

---

## 🎮 核心功能
- 🌱 **多类型方块系统**：内置草地、土路、水、石头、树木、房屋6种基础方块，支持扩展自定义材质
- ❌ **无损擦除功能**：一键清空指定格子内容，无残留、可反复修改
- 🖱️ **流畅 3D 视角控制**：支持鼠标拖拽旋转、滚轮缩放，视角操作无卡顿
- 🎯 **像素级点击放置**：射线检测精准识别网格，点击即可快速摆放物体
- 💾 **多存档本地存储**：支持3套独立存档，数据持久化到浏览器本地存储，关闭页面不丢失
- 🧱 **零门槛操作**：纯前端实现，打开即用，无需安装、无需登录、无需后端服务

## 🔧 技术架构与实现细节
### 核心技术栈
| 技术模块 | 选型 | 作用 |
| :--- | :--- | :--- |
| 3D 渲染引擎 | **Three.js** | 基于 WebGL 的 3D 渲染核心，实现场景、相机、光照、模型渲染 |
| 交互逻辑 | **Three.js Raycaster** | 射线检测技术，实现鼠标点击与 3D 网格的精准交互 |
| 前端框架 | **原生 JavaScript / 轻量响应式逻辑** | 无重型框架依赖，极致轻量化，首屏加载速度拉满 |
| 样式系统 | **CSS3** | 实现响应式UI、动画过渡、深色主题适配 |
| 数据持久化 | **浏览器 LocalStorage** | 实现多存档数据本地存储，无需后端数据库 |
| 部署方案 | **Netlify** | 静态资源 CDN 全球分发，实现秒级访问、自动部署 |

### 关键技术亮点
1.  **轻量化 3D 渲染优化**
    - 采用 InstancedMesh 批量渲染同类型方块，大幅降低 Draw Call 数量，低配设备也能流畅运行
    - 场景懒加载机制，首屏仅加载核心资源，实现 2 秒内快速打开
    - 视角自适应裁剪，超出视野范围的物体自动剔除，减少渲染压力

2.  **交互体验优化**
    - 射线检测防抖处理，避免快速点击时的误操作
    - 视角阻尼动画，拖拽旋转时自带顺滑惯性，操作手感更自然
    - 方块放置高亮预览，鼠标悬停时实时显示放置位置，降低操作门槛

3.  **数据安全与持久化**
    - 存档数据采用 JSON 序列化存储，结构清晰，支持手动导出/导入
    - 数据写入前自动校验，避免非法格式导致的页面崩溃
    - 支持多存档独立隔离，切换存档时无数据冲突

4.  **部署与工程化**
    - 纯静态资源构建，无后端服务依赖，支持任意静态托管平台一键部署
    - 资源压缩与 CDN 缓存策略，全球访问延迟极低
    - 版本化部署，支持一键回滚到历史版本，避免线上故障

## 🚀 快速开始
### 在线使用
1.  打开链接：https://3d-world-simulator.netlify.app/
2.  在右侧物品栏选择要放置的方块
3.  点击网格格子即可放置
4.  拖拽/滚轮调整视角，打造专属 3D 世界
5.  点击顶部存档按钮，保存你的创作

### 本地开发运行
```bash
# 1. 克隆项目
git clone <你的仓库地址>

# 2. 进入项目目录
cd 3d-toy-world

# 3. 启动本地静态服务（任意方式均可）
# 方式1：Python 内置服务
python -m http.server 8080

# 方式2：Node.js http-server
npx http-server .

# 4. 打开浏览器访问
http://localhost:8080
